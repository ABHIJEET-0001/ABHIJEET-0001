## 📂 Featured Projects

### 🚦 **AI Smart Traffic Management System**
An **AI-powered real-time multitasking system** using custom-trained **YOLOv11** and **OpenCV**. 

🔑 **Key Features:**
- Real-time vehicle detection & classification (bike, car, bus, truck)
- Helmet usage monitoring & compliance tracking
- Speed measurement & traffic law enforcement
- Automatic Number Plate Recognition (ANPR) via OCR & Google Cloud Vision API
- Emergency vehicle detection (ambulance, fire brigade)
- Dynamic traffic signal control based on traffic density
- Real-time cloud data upload using WebSocket & REST API
- Government-ready web platform with analytics & **automatic challan generation**
- Deployed on **Raspberry Pi** with I2C LCD display

**Technologies:** Python, YOLOv11, OpenCV, Flask, React, Google Cloud API, WebSocket, Raspberry Pi, Edge Computing

**Commits:** 21+ | **Status:** Production Ready ✅
